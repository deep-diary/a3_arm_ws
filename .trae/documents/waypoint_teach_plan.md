# 路点示教（Waypoint Teach）实施计划备忘

## 一、需求背景

根据 F131 需求（2026-09-25）：
> 长按 Share 1.5s：进入路点示教模式。操作员拖动手柄到关键位置，按下键（如 L2）打点，系统记录当前关节角度；拖动结束后，可查看已打点列表，支持增删路点；最后按 Options 保存退出，机械臂沿记录的路点运动。

## 三、实施步骤

1. **启动阶段（L3 使能 → 进入 READY）**
   - 短按 L3 一键上电开门禁+使能（默认关）
   - 退出零力矩模式，机械臂回到受控状态

2. **路点记录（Share 长按 → 进入 WAYPOINT_TEACH）**
   - Share 长按 1.5s 进入路点示教模式
   - L2 短按打点，记录当前关节角度为一个路点
   - 路点 ≥ 2 时，L2 同时触发机械臂沿已记录路点运动
   - 可随时再按 L2 继续打点

3. **路点确认与保存（Options 短按 → 保存并退出）**
   - 短按 Options：结束路点记录，保存路点列表
   - 路点 < 2：提示“至少需要 2 个路点”

4. **路点回放**
   - 机械臂依次沿记录的路点运动
   - 每个路点停留，可配置停留时间
   - 若中途松开按键，可随时停止

5. **退出路点示教（PS 键 或 Options 长按 ≥ 1.5s）**
   - 退出路点示教模式，回到正常控制模式

## 四、风险与规避

- **打点间隔过短**：相邻路点距离 < 1cm 时，提示“打点无效”
- **拖动过程中卡顿**：检查关节速度/加速度限制，避免过快运动
- **误触急停**：确保机械臂周围无障碍物，操作人员注意安全
- **同步问题**：路点记录与机械臂实际位置保持同步，避免记录到偏差位置

## 五、验收

1. 录到 3~10 个路点（推荐 5 个以上）
2. 路点之间轨迹平滑，无卡顿、无跳跃
3. 回放时机械臂准确停在每个路点
4. 结束后机械臂回到正常控制模式，READY 灯常亮
