## 结论

`smooth` 相对 `raw` 的 j_rms/a_rms 应下降 ≥ 2 个数量级（去几何量化噪声），
同时几何偏离受 ε 控制（RMS≈ε、max≈数倍 ε）。ε 越大越平滑但越偏离原始路径——
据 ε 扫描曲线在「平滑度」与「保形」之间选工作点。`standard` 仅作该时长/首末点下的平滑下限。
