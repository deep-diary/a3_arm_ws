# 9 模式 TCP 轨迹对比（口风琴 5 点，实采）

- 采集：仿真栈逐模式回放，录制 /joint_states，Pinocchio FK 到 `end_effector`。
- 位置图：TCP 在 y-z 平面（x≈-0.20）轨迹，**等比例**；速度/加速度：TCP |v|/|a| vs 时间。
