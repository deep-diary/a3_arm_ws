# A3 机械臂 PS4 手柄操作员手册（F60）

> 面向操作员：怎么开机、怎么动、怎么收工、灯和震动是什么意思。
> 键位完整参考（开发者向）见 [src/a3_teleop_ps4/README.md](../../src/a3_teleop_ps4/README.md)；
> 命令行手册见 [ROS_COMMANDS.md](ROS_COMMANDS.md)。

## 标准操作流程

### 1. 开机 + 使能（L3）

机械臂上电后，**短按左摇杆键（L3）**：执行层开门禁 + 编排层使能，一次完成。
成功时手柄 **绿灯常亮** 并 **短震一下（120 ms）**。

- 若臂长期断电过、怀疑零点丢失：先 **短按 PS 键** 做 init（调零 + 自动使能），成功时手柄 **白闪一次**。
- 上电未使能时灯为 **橙色常亮**——这是"有电但没准备好"，摇杆不会动。

### 2. 先到 ready 位，再摇杆操作（Triangle）

**短按 Triangle（▲）**，臂运行到 ready 工作位（约 3 s），过程中灯为 **紫色**，到位后回 **绿色**。

> **重要：必须先在 ready（或 home）位再推摇杆。** 机械折叠零位是 IK 奇异点，
> 直接推摇杆会不动或乱扭。

### 3. 遥控运动

| 操作 | 动作 |
|------|------|
| 按住 **L1** + 左摇杆左右 | 末端左右平移（Y） |
| 按住 **L1** + 左摇杆上下 | 末端上下平移（Z） |
| 按住 **L1** + 右摇杆上下 | 末端前后平移（X） |
| 按住 **L1** + 右摇杆左右 | 末端偏航（绕 Z 转） |
| **R2**（不用按 L1） | 夹爪直接力控：按得越深抓得越紧，松开自动全开 |
| 按住 **R1** | 速度档 1.0（全速）；松开恢复 0.35（精细档） |

- **L1 是摇杆的死人开关**：只锁摇杆，松开约 0.5 s 内臂自动停住。
- **R2 夹爪不受 L1 限制**，任何 READY 状态下都能抓。

### 4. 示教与回放

1. **短按 Share**：进入示教，灯变 **蓝色呼吸**，可徒手拖动机械臂录制轨迹。
2. **短按 Options**：结束示教并 **自动保存** 为最新轨迹，灯回绿色。（录得太短会自动跳过，不保存）
3. **短按 Square（■）**：回放刚录的轨迹，过程 **紫色**，结束回绿色。

### 5. 收工（R3）

**短按右摇杆键（R3）**：臂先自动收回到 home 折叠位（safe-park，紫色），再失能，
灯变 **橙色** 并 **短震一下**。

### 6. 紧急停止

| 操作 | 效果 |
|------|------|
| **Cross（✕）按住 1 s** | **硬急停**：整机断电、门禁关闭。灯 **红闪**、**长震 600 ms** |
| 物理急停 / Triangle 之外的安全链路 | 见 [SAFETY.md](../shared/SAFETY.md) |

硬急停后必须重新 **短按 L3** 才能恢复（重新开门禁 + 使能）。

## 灯色速查表

| 灯态 | 含义 | 能做什么 |
|------|------|----------|
| 红闪 | 失电 / 硬急停后 | 只能重新 L3 |
| 红双闪 | FAULT（故障，如越限/看门狗触发） | 排除故障后按 L3 恢复 |
| 橙色常亮 | 已上电，未使能 | 等 L3 / PS |
| 绿色常亮 | READY / SERVO，就绪 | 可摇杆、抓爪、示教 |
| 蓝色呼吸 | TEACH，示教录制中 | 拖臂，Options 结束 |
| 紫色常亮 | TRAJ：goto / 回放 / safe-park 运行中 | 等动作结束 |
| 白闪一次 | init 完成 | 随后转绿 |

## 震动速查表

| 震动 | 含义 |
|------|------|
| 短震 120 ms（弱） | 使能成功 / 失能完成 |
| 长震 600 ms（强） | 硬急停已执行 |
| 双震 | FAULT 故障进入 |

## 常见疑问

- **按了 L3 灯还是橙色？** 使能被拒绝（如关节在限位外）。查看 `/a3/arm_status` 的 message，或先按 PS 做一次 init。
- **推摇杆臂不动？** 检查：是否绿灯（READY）？是否在 ready/home 位？L1 是否按住？
- **Cross 短按没用？** 硬急停是**长按 1 s**，防止误触。
- **蓝牙连接触摸板按键无效？** 已知限制（LL-052），init 请用 PS 键。
