# A3 机械臂 PS4 手柄操作员手册（F60/F64/F189）

> 面向操作员：怎么开机、怎么动、怎么收工、灯和震动是什么意思。
> 键位完整参考（开发者向）见 [src/a3_teleop_ps4/README.md](../../src/a3_teleop_ps4/README.md)；
> 命令行手册见 [ROS_COMMANDS.md](ROS_COMMANDS.md)。

## 先选模式（F189）

按住 **Share** 不放，再按方向/面键**直接进入对应模式**（不用循环切换）：

| 组合 | 模式 | 灯色 |
|---|---|---|
| Share + ↑ | TEACH 连续示教 | 蓝呼吸 |
| Share + ↓ | WAYPOINT 路点示教 | 青呼吸 |
| Share + ← | TRACK 人脸跟踪 | 紫呼吸 |
| Share + → | PIANO 弹琴 | 黄呼吸 |
| Share + △ | DEMO 演示（先回 home） | 白呼吸 |
| Share + ○ | DANCE 舞蹈（回放最新动作） | 品红呼吸 |
| Share + □ | NORMAL 正常 | 绿常亮 |

- **Options 短按 = 退出当前模式回 NORMAL**（示教类会先保存）。
- 切模式前系统会自动先"停住当前运动"（`/a3/arm/stop`），不会带着上一个模式的动作串到新模式。
- **TEACH / WAYPOINT 进入即可拖动**：若臂还没使能，会先自动上电+使能，READY 后自动开录；
  10 s 没就绪会在日志提示"请先按 L3 上电使能"。
- **TRACK**：进入即开跟踪；`△` 短按切换跟踪开/关。画面显示：**`○` 短按**开关
  网格点/网格线/人脸框（画面中心、人脸中心、两者连线始终保留）。
  标定全部走**长按**（F191）：
  - `○` 长按 1.5 s = **水平/竖向 + 前后目标标定**（人站到你想被保持的位置再按）
  - `□` 长按 1.5 s = **前后（深度）标定**（脸/板放到 200 mm 处再按）
  - `△` 长按 2 s = **重载雅可比**（离线脚本生成的 face_jacobian.yaml）
  - `□` 短按 = 打印当前跟踪状态与标定值（看日志）
- NORMAL 的 D-pad：↑=home、↓=idle、←=前、→=后；`○` 短按 = 停止当前运动。
- **DEMO**：进入先自动回 **home**；
  - `△` 短按 = **只平移**：末端沿 X→Y→Z 依次走 `0→+6cm→−6cm→0`（z ±4.5cm），姿态不动
  - `△` 长按 1.5 s = **只平移**：连续随机方向巡游（30 s 到时，或越 6 cm / 姿态漂移 15° 自动停）
  - `○` 短按 = **只旋转**：绕 X→Y→Z 各摆一轮（末端点位置不动，约 34 s）
  - `○` 长按 1.5 s = **只旋转**：随机轴 + 随机幅度，再按一次停
  - `□` 短按 = 随机命名点巡游；`Options` = 停止并退出。
  - D-pad 不绑定。
  - 角度巡航要求臂 **READY**、且**不要同时开人脸跟踪**（会被拒绝）。

## 标准操作流程

### 1. 开机 + 使能（L3）

机械臂上电后，**短按左摇杆键（L3）**：执行层开门禁 + 编排层使能，一次完成。
成功时手柄 **绿灯常亮** 并 **短震一下（120 ms）**。

- 若臂长期断电过、怀疑零点丢失：先 **同时按住 L1+R1 约 2 秒** 做 init（调零 + 自动使能），成功时手柄 **白闪一次**。（F135 起不再用 PS 键——PS 是手柄开机键，易误触。）
- 上电未使能时灯为 **橙色常亮**——这是"有电但没准备好"，摇杆不会动。

### 2. 先到 home 位，再摇杆操作（Triangle）

**短按 Triangle（▲），臂运行到 home 工作位（F120；约 2 s）**，过程中灯为 **紫色**，到位后回 **绿色**。

> **长按 Triangle 1.5s（NORMAL 模式）**：回放旧 F176 4 键流
> `trajectories/streams/latest.yaml`（初版起手 40mm 悬停 + 键间 40/80/40mm，`ptp_blend`）。
> **F195 起口风琴改用 PIANO 模式**：抬升量按两键距离比例缩放、进场/离场垂直悬停、末段回 home，
> 详见 §4.4 口风琴（PIANO 模式）。
> 想换规划方式：直接改目标文件各段的 `mode:` 存盘即生效（文件头有 F166 九模式速查，无需重建/重启）。

> **重要：必须先在 home（或 idle）位再推摇杆。** 机械折叠零位是 IK 奇异点，
> 直接推摇杆会不动或乱扭。

### 3. 遥控运动

| 操作 | 动作 |
|------|------|
| 按住 **L1** + 左摇杆左右 | 末端左右平移（Y） |
| 按住 **L1** + 左摇杆上下 | 末端上下平移（Z） |
| 按住 **L1** + 右摇杆上下 | 末端前后平移（X） |
| 按住 **R1** + 右摇杆左右 | 末端偏航旋转（绕 Z 转） |
| 按住 **R1** + 右摇杆上下 | 末端俯仰旋转（绕 Y 转，抬腕/低头） |
| 按住 **R1** + 左摇杆左右 | 末端滚转旋转（绕 X 转） |
| **D-pad 上 / 下 / 左 / 右** | 一键 goto 口风琴实测定位点（均「未按压」基准点，按键盘空间）：左=white1（F3）/ 右=white19（C6）/ 上=black13（A#5）/ 下=black1（F#3）（F176，`melodion_white1`/`melodion_white19`/`melodion_black13`/`melodion_black1`） |
| **R2**（不用按 L1/R1） | 夹爪直接力控：按得越深抓得越紧，松开自动全开 |

- **L1 / R1 是两个死人开关**：L1 只放行平移摇杆，R1 只放行旋转摇杆；
  同时只动一类运动，松开约 0.5 s 内臂自动停住。
- **R1 的旋转是"原地转"**：姿态变、末端点位置不变（`a3_servo_target` 按绕末端点积分）。
  想要"绕基座画弧"的旧行为，把 `rotation_about_tip` 置 false。
- **平移/旋转速度恒为默认档 0.35**（F115 起 D-pad 不再调速；`step_*_scale`
  动作函数仍保留，自定义映射可自行绑定）。
- **D-pad 一键到位走 MoveIt 规划**（同 Triangle/Circle，过程紫色）；按住不连发、
  回中后才能再按，且一次 goto 服务返回后有约 3.5 s 按键封锁窗（防连打叠加轨迹）。
- **R2 夹爪不受死人开关限制**，任何 READY 状态下都能抓。

### 4. 示教与回放

#### 4.1 连续轨迹示教（精细路径）

1. **短按 Share**：进入示教，灯变 **蓝色呼吸**，可徒手拖动机械臂录制轨迹。
2. **短按 Options**：结束示教并 **自动保存** 为最新轨迹，灯回绿色。（录得太短会自动跳过，不保存）
3. **短按 Square（■）**：回放刚录的轨迹，过程 **紫色**，结束回绿色。

#### 4.2 路点示教（F131，离散点位任务）

1. **长按 Share 1.5 s**：进入路点示教，灯变 **青色呼吸**，可徒手拖动机械臂。
2. **短按 L2**：在当前位置**打一个路点**，灯 **白闪 0.4s + 弱震** 确认。（相邻路点距离过近会自动去重）
3. **短按 Options**：结束路点示教并 **自动保存** 为最新路点文件，灯回绿色。
4. **长按 Square 1.5 s**：**PTP 回放**——关节空间插值（MoveJ），路径不限制但末端可能走曲线，最常用。多点**整序列一次规划、连续执行**（F134 pilz Sequence + 过弯 blend，中间点不停车；段间距过小的点会在该处短暂停顿）。
5. **长按 Circle 1.5 s**：**LIN 回放**——笛卡尔空间走**直线**，路径受控，适合插装/涂胶/对齐；同样整序列连续过弯。若某段直线跨奇异或关节加速度超限，会**明确拒绝并提示改用 PTP**，不会自动降级。
6. **触摸板单击**（暂缓启用，见 F132）：与 Circle 长按等效触发 LIN 回放。

> **误触防护**：连续轨迹和路点文件分开存储；Square 短按只回放连续轨迹，长按只回放路点；反之亦然。

#### 4.3 其他

4. **长按 Options 3 s（READY 绿灯态）**：**F116 随机点位巡游**——从 `named_poses.yaml`
   随机抽 5 个命名点（排除 `zero`，相邻不重），从当前位姿起**整序列一次规划、连续执行**
   （F134 pilz Sequence + blend 过弯不停车，过程 **紫色**；不安全/越限点位自动重抽），结束回绿色。
   仅 READY 态生效；示教中/运动中长按会被安全拒绝（示教时请用短按结束）。
   中途随时可 **R3** 软失能或 **✕** 硬急停中断。

#### 4.4 口风琴（PIANO 模式，F195）

选模式：**按住 Share + →** 进入 PIANO（黄呼吸）。轨迹全部落在
`trajectories/melodion/{waypoints,streams}/`，与通用示教/巡游分开。

| 操作 | 动作 |
|------|------|
| **D-pad ↓** | 开始**演奏路点示教**（`melodion/waypoints/press.yaml`）；L2 在「已按下」位置打点 |
| **D-pad ←** | 开始**4 极限键录制**（`melodion/waypoints/extremes.yaml`）；顺序：白键最左(F3) → 白键最右(C6) → 黑键最右(A#5) → 黑键最左(F#3)，每键 L2 打点 |
| **D-pad →** | **结束示教并保存**到当前槽位（同时写 `teach_wp_*.yaml` 时间戳备份） |
| **D-pad ↑** | **生成按键 stream**：由两个路点槽生成 `streams/press.yaml` 与 `streams/extremes.yaml`（不运动） |
| **△ 短按** | 播放 `streams/press.yaml`（演奏路点生成的按键轨迹） |
| **○ 短按** | 播放 `streams/extremes.yaml`（4 极限键轨迹） |
| **□ 短按** | 播放 `streams/music.yaml`（曲谱生成，需先跑 `scripts/melodion_score_stream.py`） |

- 按键轨迹：每个路点是**按下点**；键间抬升量按两键水平距离缩放
  （源/目标正上方 `press+0.5·d`，中垂线上方 `press+1.0·d`，夹紧 20–60mm）。
- 目标键正上方默认 **blend 切角**（切点仍在键面上方 ≥8mm，之后竖直下压）；
  真机若发现压键边/邻键，生成时加 `--target-exact`（停稳后再压）。
- 进场先到第 1 键正上方并**停稳**再垂直下压；离场先垂直抬起末键，再回 `home`，
  避免斜着进出把口风琴拖走。
- 每条按键 stream 的每段可带 `sleep`（按住时长）；`music.yaml` 的 sleep 来自曲谱时值。

### 5. 收工（R3）

**短按右摇杆键（R3）**：臂先自动收回到 idle 折叠位（safe-park，紫色），再失能，
灯变 **橙色** 并 **短震一下**。

### 6. 紧急停止

| 操作 | 效果 |
|------|------|
| **Cross（✕）按住 1 s** | **硬急停**：整机断电、门禁关闭。灯 **红闪**、**长震 600 ms** |
| 物理急停之外的其它安全链路 | 见 [SAFETY.md](../shared/SAFETY.md) |

硬急停后必须重新 **短按 L3** 才能恢复（重新开门禁 + 使能）。

> **硬急停后可以安全人工挪臂（F66，LL-070）。** X 急停会作废全部运动目标；急停后人工把臂搬到任意姿态，再按 L3，电机会**以当前实际位置为起点**软起步使能，不会跳回急停前的位置（2026-09-22 前因裸 CAN 使能绕过使能重锚，臂被甩回旧位姿曾两次甩断 L6/L7）。若 L3 后仍橙灯（编排层 DISABLED 但电源序列仍在 Running 的恢复死锁），F66 起 L3 会走使能恢复通道直接转绿；仍失败时查 `/a3/arm_status` message 或长按 X 完整关机后重来。

## 灯色速查表

| 灯态 | 含义 | 能做什么 |
|------|------|----------|
| 红闪 | 失电 / 硬急停后 | 只能重新 L3 |
| 红双闪 | FAULT（故障，如越限/看门狗触发） | 排除故障后按 L3 恢复 |
| 橙色常亮 | 已上电，未使能 | 等 L3 / PS |
| 绿色常亮 | READY / SERVO，就绪 | 可摇杆、抓爪、示教 |
| 蓝色呼吸 | TEACH，连续示教录制中 | 拖臂，Options 结束 |
| 青色呼吸 | WAYPOINT_TEACH，路点示教中 | 拖臂，L2 打点，Options 结束 |
| 紫色常亮 | TRAJ：goto / 回放 / safe-park 运行中 | 等动作结束 |
| 白闪一次 | init 完成 | 随后转绿 |

## 震动速查表

| 震动 | 含义 |
|------|------|
| 短震 120 ms（弱） | 使能成功 / 失能完成 |
| 长震 600 ms（强） | 硬急停已执行 |
| 双震 | FAULT 故障进入 |

## 常见疑问

- **按了 L3 灯还是橙色？** 查看 `/a3/arm_status` 的 message：关节在限位外/温度保护等会被拒，先 L1+R1 同按 2 秒做一次 init 或按提示恢复。注：开机电源序列已自动使能电机时，L3 不会再重复使能、会直接转绿（正常现象，F65）。
- **推摇杆臂不动？** 检查：是否绿灯（READY）？平移要按住 **L1**、旋转要按住 **R1**；首次推摇杆时系统会自动启动 Servo（约 1 s 内开始动，非故障）。机械零位是 Servo 奇异点（LL-007），jog 前先按 **Circle 回 idle** 或 **Triangle 回 home**。
- **速度太快/太慢？** F115 起 default 映射速度恒定默认档 0.35，D-pad 已改为 home 周边 4 点位快捷 goto，不再调速；需要调速可在自定义映射里绑定保留的 `step_linear_scale/step_angular_scale` 动作。
- **Cross 短按没用？** 硬急停是**长按 1 s**，防止误触。
- **蓝牙连接触摸板按键无效？** 已知限制（LL-052），init 请用 **L1+R1 同按 2 秒**（F135 起 PS 键已解绑）。
