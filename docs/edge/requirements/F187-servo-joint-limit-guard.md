# F187 — 视觉伺服关节限位软门（防"顶到限位再堵转"）

- **说明：** 2026-10-24 开启转动跟踪（`enable_angular`）后连续发生两次真机事故，
  共同点是「某个关节顶到机械限位后，控制器还在要求它继续走」：

  | # | 现场 | 证据 | 后果 |
  |---|---|---|---|
  | 1 | L5 在 1 s 内冲到 **+1.74 rad**（超 +1.5708 上限 9.6°） | `Ja` 标定后 `ka=0.8 / w_max=0.6`；黑匣子显示 1 s 内 L1 +1.0 / L4 +0.5 / L5 +1.2 rad | `motor fault L5 mask=0x10`（FAULT_STALL）→ emergency reset |
  | 2 | L4 先顶到 **−1.047 下限**，3 s 后 L5 被拖到 **+1.657**、L3 到 **+0.0305** | 伺服日志：`err 4.5→16.2→37.5 mm`、`ik_fail 6/6`、`IK 解远离实测 0.215（累计 109）` | L4 堵转 `mask=0x10` → FAULT；**L5 连杆机械断裂** |

  关键机制（事故 2）：L4 已经被夹在限位上，但**平移**分量（`lin_frac=0.5`，仍可达 20 mm/s）
  继续要求 IK 重构保持末端点 → 笛卡尔目标继续积分 → 换支 → 把别的关节一起拖过限位。
  事故 2 时软门 v1 **已经生效**（日志 `转动指令 ×0.42/×0.47`），但它只管"转动"、只管 L4–L6。

- **验收标准：**
  1. 每条控制周期用 `J⁻¹·[v; w]`（完整 twist，末端点不动）求出关节速度方向；
  2. 对每个关节：仅当该方向**朝限位走**时按余量线性收缩（余量 `joint_margin_deg`=15° 开始、
     半程 7.5° 归零）；朝外运动一律 1.0（保证能自己退回）；
  3. ~~**贴限位硬门**：任一关节余量 < 7.5° 或已越 URDF 限位 → 整拍命令归零（与方向无关）~~
     **2026-10-26 改为逐维锁定（原实现会把臂**永久冻死**）**：进入 7.5° 余量带的关节，
     把 `qd[i]`（= `J⁻¹·[v;w]` 的第 i 个分量）按余量缩到 0，再用 `twist' = J·qd'` 映射回
     笛卡尔 → **只锁该维，反向（退出限位）与其它关节/轴照常**。已越 URDF 限位仍整拍停
     （交给人工，最后兜底）。
     事故现场：L4 = −55.4°（余量 4.6°）时旧逻辑每拍返回 0 → 臂既不能往里也不能往回 →
     余量永远不涨 → 把 pad 移回画面中央也**不恢复**，只能人工回 home。新逻辑下同一姿态
     仍可做深度/横向动作，且 L4 一旦被指令往回带就自动解除。
  4. 收缩对**平移和转动同时生效**；
  5. pinocchio / URDF 不可用时自动降级为"不干预"，并在日志说明（不影响其它功能）。

- **伺服侧命令夹紧（同一需求的底层，2026-10-24 补）：**
  URDF 限位原本只夹住 **IK 解**（`q_goal_`），**没夹真正发出去的命令状态 `q_cmd_`**：
  `q_cmd_[i] += qd_cmd_[i] * dt_step;` 只限速度（`max_vel_`）。
  而 `vj_f_`（twist → 关节的前馈）只看"末端要多快"，不看关节余量，于是 IK 跟不上时
  `pos_gain·(q_goal−q_cmd)` 拉不住，`q_cmd_` 被一路积分到限位外 —— 黑匣子里
  **L4 命令 −1.48（限位 −1.047）、L5 命令 +1.78（限位 1.5708）**，MIT 位置环按
  `kp·(q_cmd−q_meas)` 顶死（kp≈100、误差 0.3–0.5 rad → 30–50 Nm，L5 额定 3 Nm 级），
  约 4 s 后才由 EL05 堵转保护（`mask=0x10`）切断，**期间拉断 L5 连杆**。

  修法（`servo_target_node.cpp`）：积分后把 `q_cmd_` 夹到 `[joint_lo+cmd_limit_margin,
  joint_hi−cmd_limit_margin]`（默认 0.02 rad ≈1.1°），到限位即把该关节 `qd/qa` 置 0，
  并 `WARN` 节流上报（`命令到限位：<joint> q_cmd=...`）。这层比 Python 侧软门快
  （控制周期内、无 10 Hz `ArmStatus` 滞后），是最后一道"命令不越界"的保证。

  夹紧边界与**实测**取包络：`lo = min(joint_lo+余量, q_meas)`、`hi = max(joint_hi−余量, q_meas)`。
  否则合法姿态若本来就在余量带内（idle 的 `L2≈0.015`，下限 0.000 + 余量 0.020），
  命令会被顶到 0.020 → 常驻 ~0.4 Nm 偏置顶着电机发热、且每 2 s 刷一条 WARN。
  取包络后语义是"实测已在带内 → 最多退到实测处，不许再往限位里走"。

- **实现：**
  - `src/a3_perception/a3_perception/face_track_controller.py`
    - `_init_joint_limits()`：从 `a3_robot_model` 的 URDF 建 pinocchio 模型，取 L1–L6 限位
    - `_limit_twist(v, w) -> (v', w', note)`：越限即整拍停 → `qd = J⁻¹[v;w]` →
      **只缩放朝限位走的 `qd[i]`**（15°→1，7.5°→0）→ `twist' = J·qd'`；
      `note` 非空时打印 `关节限位 → L4 余量 4.6°→锁（仅限该维，其它方向保留）`
    - 调用点在 v/w 限幅与斜坡**之前**（斜坡会把"归零"平滑成 0.1–0.4 s 的减速）
  - 参数：`joint_guard`（默认 true）、`joint_margin_deg`（15）；运行时 `ros2 param set` 可调
  - 配套收紧：`enable_angular` 默认 **true**、`ka` 0.8→**0.3**、`w_max` 0.6→**0.15**、`w_ramp` 2.0→**0.4**
