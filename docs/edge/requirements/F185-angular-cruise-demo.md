# F185 — 三轴角度巡航 demo（绕末端点连续摆幅 + 速度可调 + 精度回归）

- **说明：** F184 把 servo 的角速度语义改成"绕末端点旋转"后，验收脚本 `f183_servo_rotation_check.py`
  是**逐项**测（每轴正负各转 0.1 rad，段间停 0.5 s）。演示/精度验证需要另一种形态：

  - **连续**：每轴一趟 `0 → +A → −B → 0`，段与段之间不停顿，三轴接力；
  - **尽可能大的摆幅**：摆幅不由手感拍定，而是用与控栈同一份 URDF 做**运动学仿真**扫描
    （末端点固定、关节不越限）得出上限，再留余量；
  - **速度可调**：一个峰值角速度参数，便于比较不同速度下的跟踪/精度；
  - **可当精度尺**：把工具尖顶在一个参考点上跑完整个序列，末端点理论上全程不动、
    结束时回到原姿态 → 末端漂移量直接反映伺服精度与重复性。

- **验收标准：**
  1. `--analyze` 不动机器即可给出各轴正负的最大可行摆幅与"最先顶到的关节"
  2. 默认摆幅来自该扫描结果（留 3–10° 余量），`--amp x=85/85` 可覆盖
  3. 连续执行 `X(+A,−B,+A) → Y(...) → Z(...)`，无中间停顿；每轴净转角为 0
  4. 峰值角速度可调（默认 30°/s），速度包络为正弦（段端点速度自然为 0，无冲击）
  5. 全程末端点 3D 漂移 ≤ 8 mm（超限立即中止），结束时位置残差 ≤ 3 mm、姿态残差 ≤ 1°
  6. 硬件异常（`state` 掉出 READY / `/a3/hardware/feedback_stale`）立即中止并说明原因

- **摆幅上限（运动学仿真，2026-10-24，`el_a3` URDF / 6 关节 / home=[0,.785,−.785,0,0,0]）：**

  | 轴 | 最大可行 | 受限关节 | 默认摆幅（留余量）|
  |---|---|---|---|
  | X（滚转，≈工具轴）| ±90° | L6 ±90° | ±80° |
  | Y（俯仰）| +28° / −53° | L4 −60°…+90° | +25° / −45° |
  | Z（偏航）| ±55° | L5 ±90° | ±45° / ±45° |

  要点：**home 是全伸位形**，绕末端点做纯姿态旋转必须整臂重构来保住末端点，因此
  Y/Z 的实际可用摆幅远小于 X（X 基本只动 L6），且 Y 因 L4 限位不对称而两个方向不等。
  想要更大幅度需换半折基准位形（不在本需求范围）。

- **实现：**
  - `scripts/a3_test/f185_angular_cruise_demo.py`
    - `--analyze`：pinocchio FK/阻尼最小二乘 IK，从 home 起 1° 步进扫描（种子取上一度解，保证连续，
      与 servo 端 CLIK 同解支），顶到限位或无解即停
    - 运行：`sin` 速度包络 `v(t)=v_peak·sin(πt/T)`，`T=π|Δ|/(2·v_peak)`；只发 angular，linear 恒 0
      → `a3_servo_target` 只改姿态、末端点不动
    - 精度统计：起点/每段/终点的 `/a3/ee_pose`，报告每段实测角、Δp、全程最大漂移、终点残差
    - `--auto-enable`：代替手柄做「门禁 start → `/a3/arm/enable` → goto home」
  - 依赖：真机栈（`a3_servo_target`）、`/a3/ee_pose`；人脸跟踪必须关闭（同一 twist 话题）

- **实测（2026-10-24，真机 RK3588 + 6 关节档，home 基准；`--auto-enable` 自动使能）：**

  三轴连跑（x,y,z 一次跑完，段间不停）：

  | 速度 | 实测角（X / Y / Z 三段）| 段末 Δp | 全程最大漂移 | 终点残差 | 结果 |
  |---|---|---|---|---|---|
  | 30°/s | X 80.0/159.9/79.9°；Y 25.3/69.8/44.9°；Z 45.1/89.9/44.9° | ≤2.9 mm | 3.91 mm | 2.69 mm / 0.48° | PASS |
  | 35°/s | X 79.9/159.8/79.8°；Y 25.4/70.6/44.6°；Z 45.0/90.1/44.8° | ≤2.2 mm | 3.65 mm | 1.11 mm / 0.85° | PASS |

  速度上限（单轴各跑，判据同 F185 验收第 5 条）：

  | 轴 | 可用 | 实测表现 | 受限原因 |
  |---|---|---|---|
  | X | ≤60°/s | 60°/s：80.2/160.1/79.7°，Δp ≤1.7 mm | 90°/s 时角度只到 88%（L6 需 1.57 rad/s，贴 `max_joint_velocity=1.5`）|
  | Y | ≤40°/s | 40°/s：25.7/71.2/45.3°，Δp ≤2.7 mm | 60°/s 跟不动（只走 13.8°，Δp 20 mm）——俯仰靠整臂重构，L4 ≈2×工具角速度，超关节限速 |
  | Z | ≤35°/s | 35°/s：45.1/90.2/45.2°，Δp ≤2.8 mm | 40°/s 时 90° 长段只走 71.4°、Δp 8.6 mm，L5 到限速 |

  结论：**三轴连跑默认用 30°/s（保守）或 35°/s**；只看 X 滚转可提到 60°/s。
  角度复现误差 ≤0.5°（≤35°/s），末端点漂移 1–3.9 mm，跑完整圈回原姿态残差 <1°。
  原因一致：X 基本只动 L6（1:1），Y/Z 要整臂重构、关节速度需求约 2× 工具角速度，先撞 1.5 rad/s 限速。

- **实现细节补充：** 起跑前必须收到一帧 `/a3/ee_pose`，否则拒绝运行（DDS 发现偶发慢于启动等待，
  未收到就会以原点为基准算漂移，实测出现过 `起点 tip=(0,0,0)` → Δp 411 mm 的假数据）；
  运行中同时监控 `state`、`/a3/hardware/feedback_stale` 与 Δp，任一异常立即中止并说明原因。
