# F170 — 全行程重力标定网格档（F49 `--mode space`，覆盖真机实际示教行程）

- **说明：** F49 的采集网格（`full`/`high`/`ultra`）沿用官方参考范围，**窄于本臂实际行程**——L2 上限 1.5/1.6、L3 下限 -1.3/-1.4，而本臂 URDF 限位 L2∈[0,3.665]、L3∈[-4.014,0]，实际示教常到 L2≈2.4、L3≈-2.1、L4≈-0.25。示教模式（`WAYPOINT_TEACH`/`ZERO_TORQUE`，**kp=0**，见 [a3_mit_hardware_interface.cpp](../../../src/a3_hardware_interface/src/a3_mit_hardware_interface.cpp#L1104-L1132)）没有位置弹簧兜底，**网格外区属外推**，模型误差被放大 → L3 欠补偿 → 示教时下塌。READY 实测佐证：后仰位 `home_back` 模型 L3 = -2.01 Nm vs 实测 -2.25 Nm（**少 0.24 Nm**），前伸 `home_front` 少 0.12 Nm。本需求新增「全行程档 `space`」，采样范围按本臂实际可达行程设定，消除示教常用区的外推下塌。**其余档位行为不得改变。**

- **验收标准：**
  1. `--mode space` 生成的网格覆盖 L2∈[0, 2.4]、L3∈[-2.1, -0.2]、L4/L5 延伸到负值侧；`quick`/`full`/`high`/`ultra` 逐字不变
  2. 每点仍过碰撞过滤 + τ 预测跳过（`--torque-skip`）+ 温度守护，逻辑不变
  3. 真机采集（6J）后拟合 RMSE ≤0.15 Nm；示教常用区（L2 1.9–2.4、L3 -1.3–-2.0）模型 vs 实测 |Δτ| 显著优于旧 `full` 档
  4. 示教（kp=0）下，原下塌位姿 L3 不再明显下塌

- **关联：** F49（重力模型标定）、F169（标定入口 + 6J 适配）、F168（产品栈 6 关节档）、[LL-035](../../lessons_learned/LL-035-gravity-rest-anchor-non-sample.md)（折叠 rest 非重力样本）、[LL-038](../../lessons_learned/LL-038-gravity-hardware-floor.md)（硬件地板）

- **实现：**
  - `scripts/gravity_calibration.py` `generate_test_configurations`：新增 `space` 档——`l2∈linspace(0,2.4,11)`、`l3∈linspace(-2.1,-0.2,11)`、`l4∈linspace(-0.5,1.3,6)`、`l5∈linspace(-0.4,1.1,4)`，`grid_step=2`；`--mode` choices 加 `space`
  - **力矩跳过阈值（本轮决策）**：默认 3.5 Nm 会跳过 L2≥1.92 的整片后仰区（正是要治的区域）→ 本轮取 **`--torque-skip 4.5`**（保留 0.5 Nm 余量到 F42 的 5 Nm 钳位）。最极端 5 个角点（(2.4,-2.1)(2.4,-1.72)(2.4,-1.34)(0,-2.1)(0,-1.72)）预测 τ>4.5，**物理不可采**（超钳位/臂撑不住），属硬件天花板
  - 6J 采集：`--joints 6 --mode space --no-rest-anchor --torque-skip 4.5 --anchors <示教位>`
  - **末端高度过滤 `--min-tip-z`（本轮新增，压桌防护）**：全行程档把 L2 后仰到 2.4 时，末端（`end_effector` 帧）会伸到 **基座平面以下**（L2=2.4/L3=-0.79 时末端 z=-0.022 m），真机基座与桌面等高 → **压桌**（首次真机采集因此在 L2=2.4 处卡死、后续 JTC 全部 `goal_time_tolerance` 超时）。新增 FK 末端高度过滤：剔除末端 z < `--min-tip-z`（默认 0.05 m）的位姿——本轮剔除 3 点（L2=2.16/-0.785、L2=2.4/-0.785、L2=2.4/-0.96），剩 68 点。默认值对旧档位无影响（旧档末端最低≈0.12 m）。

- **状态：** `implemented`（2026-10-14）
  - 网格 dry-run：`space` 档共 76 点 → τ 过滤（4.5）后 71 点 → 末端高度过滤（0.05）后 **68 点**
  - 真机采集（6J，拆夹爪）：见下方「实测结果」

- **实测结果（2026-10-14，6J 拆夹爪）：**
  - **采集 73/73 全成功**（含锚点 = 示教塌点位姿 `2.38,-2.05,0.60,0.02`，τ≈3.8 < 4.5）。峰值温度 65°C，无需降温暂停。
  - **拟合 RMSE 0.1483 Nm / R² 0.9744 → PASS（≤0.15）**；同批数据旧 `inertia_params.yaml` 基线 RMSE 0.1813 → **新参数优 0.033 Nm**。yaml 已写（`inertia_params.yaml.bak-20261014_190045` 留旧版）。
  - 逐关节残差：L2 rmse 0.309（方向性迟滞 ±0.170）、L3 0.110、L4 0.034、L5 0.038、L6 0.003。**L2 的 0.17 Nm 方向性迟滞是示教（kp=0）静态残差地板**（LL-038）。
  - **关键突破**：τ 过滤改用「已标定模型」后（起初用 URDF 默认惯量高估 ~40%），`(2.4,-2.1)`、`(2.4,-1.72)`、`(1.92,-2.1)`、`(1.92,-1.72)` 等**后仰极值点从"被跳"变为"可采"** → 后仰区首次进网。
  - **生效方式**：需**重启栈**——硬件（F108 `el_a3_ros2_control.xacro` 的 `inertia_config_path`）与 `zero_torque_controller` 均只在启动时读 `inertia_params.yaml`。
  - **过程教训**：首次真机采集因 (2.4,-0.79) 末端伸到基座平面下而压桌、卡死并连带后续 JTC 全超时 → 新增末端高度过滤；栈长时间运行 + 断网后 DDS/执行层退化（全点 `goal_time_tolerance`、topic 读空）→ **重启栈即恢复**。

  - **收尾修正（LL-160）**：初次拟合用的 URDF 含**幽灵夹爪**（`L7_joint`+`gripper_link` 0.05 kg，nq=7），而真机无夹爪（nq=6）→ 拟合把 L2–L6 质量压低 ~0.06 kg → 消费端 6J 套用后**系统性欠补偿、示教到处下塌**。已改为 `--joints 6` 在 `init_pinocchio` 自动清零夹爪惯量，并用**同批数据离线重拟合**（`--optimize-only`，无需重采）：RMSE 不变 0.1483，质量每根抬高——L2 0.658→0.679、L3 0.183→0.189、L4 0.410→0.429、L5 0.016→0.018、L6 0.482→0.500（合计 +~0.06 kg）。`inertia_params.yaml` 已用 6J 版覆盖。
  - **遗留**：L2 的 ±0.170 Nm 方向性迟滞是硬件地板；示教 `kp=0` 无位置弹簧下，任何残差都转为稳态漂移（`v≈Δτ/kd`）→ 静态模型无法让示教完全不塌，彻底改善需摩擦/迟滞补偿或示教加小刚度。**2026-10-14 试缓解**：把示教 F85 速度自适应阻尼的低速档 `kd_max` 从 0.05–0.15 分两步加大——先 0.6–0.8，再由用户要求 ×4 到 **全局/L2/L3 3.2、L4/L5/L6 2.4**（`el_a3_ros2_control.xacro`，`kd_min` 仍 0.001–0.005 不影响快拖），仅减慢漂移速度、不消除。

  - **收尾修正 2（LL-161，关键）**：`space` 档 `l2∈linspace(0,2.4)` 从 0 起，而 **L2 限位下限=0** → 7 个 `l2=0` 的点**顶在机械止挡**上，止挡分担重力使实测 τ 偏小 0.5–0.9 Nm（非重力样本）→ 把 L2 参数整体拉偏（**L2 rmse 0.309、示教 L2 到处塌**）。新增 `--limit-margin`（默认 0.10 rad，任一关节距限位过近即剔除）；**剔除那 7 点离线重拟合**：RMSE **0.148→0.1007**、L2 rmse **0.309→0.188**、L2 质量 **0.679→0.704**、L2 迟滞 ±0.170→±0.101。`inertia_params.yaml` 已用该 66 点版本覆盖。旧 `full` 档 `l2` 从 0.3 起、天然避开止挡，故未暴露此问题。

  - **v2 补采（2026-10-14 晚）**：示教发现「L3 大弯 + L4 负」这类**交叉组合**（轴对齐网格未覆盖）仍欠补偿 → 追加 8 个锚点重采，**73/73 全成功**，拟合 RMSE **0.1013**（L2 0.188→0.160、L2 质量 0.704→0.707）。`inertia_params.yaml` 已更新（`bak-20261014_224840`）。同轮把示教 L5/L6 `zero_torque_kd_max` 由 0.6 调到 **0.3**（用户反馈腕部阻力偏大）。
