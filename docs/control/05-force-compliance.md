# 05. 力控与柔顺 — 进阶清单

> **定位：** 让机械臂不只是「位置机器」，而是能与环境**接触**——控制接触力、顺应外力、完成装配/抛光/表面跟踪等任务。
> **覆盖 [CONTROL_ROADMAP](../shared/CONTROL_ROADMAP.md) 层级：** L8（力控与柔顺，可选 / 硬件依赖）。
> **涉及本仓需求：** F25/F33（夹爪力外环，非腕部六维）、以及 [CONTROL_ROADMAP](../shared/CONTROL_ROADMAP.md) 的 C8（末端力控）。
> **图例：** ✅ 已实现 · ⚠️ 部分实现 · ❌ 未实现 · 🔜 已立项规划 · ※ 社区非官方
>
> ⚠️ **编号说明：** 本模块级别用 `C0–C8`，与 [CONTROL_ROADMAP](../shared/CONTROL_ROADMAP.md) 的 Wave B 落地项 `C1–C8`（C2 插值 / C1 真机闭环 / C3 重力补偿…）**含义不同、请勿混淆**。

## 2. 逐级详解

### C0 — 关节层阻抗（MIT kp/kd 软化）

- **是什么：** 通过把 MIT 位置环的 kp/kd 调软，使关节在外力下「让一点」，看起来柔顺。
- **新增功能点（相对纯刚性位置控制）：** 关节层有了可调柔性，人手可推动、接触时不易硬顶。
- **关键方法 / 组件：** 关节 kp/kd 调节、自由拖动速度自适应 Kd。
- **工业对标：** 关节空间阻抗（joint impedance）。
- **本仓状态：** ✅ [F73](../edge/requirements/F73-torque-command-mode-zero-torque.md)（零力矩控制器）、[F85](../edge/requirements/F85-free-drive-adaptive-kd.md)（自适应 Kd）。
- **验收 / 自测点：** 关节可被推软/推硬。
- **⚠️ 重要边界：** 电机 MIT 的 kp/kd **不是** L8 末端力控——把关节调软 ≠ 基于末端六维力的柔顺（见 [SAFETY.md](../shared/SAFETY.md) 与 [CONTROL_ROADMAP](../shared/CONTROL_ROADMAP.md) 1.3）。

### C1 — 末端 F/T 传感器接入

- **是什么：** 加装腕部/法兰六维力/力矩传感器，读取 Fx,Fy,Fz,Mx,My,Mz。
- **新增功能点（相对 C0）：** 从「感知不到接触」到「测得真实接触力」——所有真正的笛卡尔力控都以此为前置。
- **关键方法 / 组件：** F/T 驱动、去零偏（bias）、滤波、**传感器自身重力/负载补偿**（把工具自重从读数里扣掉）。
- **工业对标：** ATI/宇立等六维力传感器、Franka 内置关节力矩推算末端力。
- **本仓状态：** ❌ 未实现（**无硬件**）；[CONTROL_ROADMAP](../shared/CONTROL_ROADMAP.md) 列为 C8 前置。
- **验收 / 自测点：** 空载读数接近零（扣重力后）；施加已知力可复现。

### C2 — 力/位混合控制（选择矩阵）

- **是什么：** 用选择矩阵 S 把任务空间分成「控力方向」与「控位方向」，同时约束力与位置（如沿面法向控力、切向控位）。
- **新增功能点（相对 C1）：** 从「整臂一种策略」到「按方向分工」——沿表面滑动、压紧装配这类任务的关键。
- **关键方法 / 组件：** 混合力/位控制（Hybrid force/position control）、选择矩阵、约束坐标系。
- **工业对标：** Raibert-Craig 混合控制、工业臂的力/位混合。
- **本仓状态：** ❌ 未实现。
- **验收 / 自测点：** 指定方向力恒定、另一方向位置精确。

### C3 — 阻抗控制（位置型）

- **是什么：** 让末端表现为一个「质量-弹簧-阻尼」系统，用位置修正实现期望的力-位移关系（`F = M·ẍ + D·ẋ + K·x`）。
- **新增功能点（相对 C2）：** 从「刚性约束」到「柔顺响应」——接触时自然退让，不需要精确知道环境刚度。
- **关键方法 / 组件：** 阻抗控制（位置型）、目标惯量/阻尼/刚度、笛卡尔阻抗。
- **工业对标：** Franka Cartesian Impedance、KUKA LBR iiwa 的柔顺模式。
- **本仓状态：** ❌ 未实现（本仓 Servo/零力矩非笛卡尔阻抗）。
- **验收 / 自测点：** 接触刚度改变时行为符合设定阻抗；无失稳振荡。

### C4 — 导纳控制（力→位置修正）

- **是什么：** 以力传感器为输入，通过导纳（admittance）把测得的力转成位置修正量，再交给位置内环执行。
- **新增功能点（相对 C3）：** 从「位置型阻抗」到「基于实测力的闭环」——对刚性/粘性环境更稳，工业上更容易接现有位置控制器。
- **关键方法 / 组件：** 导纳控制、力→位置滤波、`ros2_control` 的 `admittance_controller`。
- **工业对标：** 导纳控制（admittance control）、`admittance_controller`。
- **本仓状态：** ❌ 未实现；标准栈已就绪（模块 01 D7），**有 F/T 后可挂 `admittance_controller`**。
- **验收 / 自测点：** 施加外力末端平顺跟随；接触稳定。

### C5 — 直接力控制（力闭环）

- **是什么：** 直接以力为目标做闭环，恒定压紧或跟踪设定力曲线。
- **新增功能点（相对 C4）：** 从「柔顺」到「力可设定」——需要精确控制接触力大小（如夹持、压装）。
- **关键方法 / 组件：** 力环 PI/PID、力曲线跟踪。
- **工业对标：** 力控制（force control）、恒力打磨。
- **本仓状态：** ⚠️ 部分——**仅夹爪**力外环（位置内环 + PI 力外环）：[F25](../edge/requirements/F25-gripper-adaptive-force-control.md)、[F33](../edge/requirements/F33-gripper-force-behavior-fix.md)；**末端（腕部六维）力控未实现**。
- **验收 / 自测点：** 夹爪握力可设定并稳定；末端恒力未实现。

### C6 — 变阻抗 / 学习型阻抗

- **是什么：** 阻抗参数随任务阶段或通过学习方法变化（接近时软、装配时硬、插入时再软）。
- **新增功能点（相对 C5）：** 从「固定刚度」到「按阶段/经验调参」——复杂接触任务的自适应能力。
- **关键方法 / 组件：** 变阻抗（VIC）、学习型阻抗（reinforcement/imitation）、刚度调度。
- **工业对标：** 变阻抗控制、学习型柔顺（学术 + 前沿工业）。
- **本仓状态：** ❌ 未实现（对标缺口）。
- **验收 / 自测点：** 多阶段任务中刚度切换平滑、成功率提升。

### C7 — 接触任务

- **是什么：** 把上述力控能力用于具体工艺：轴孔装配（peg-in-hole）、抛光/打磨、表面跟踪/涂胶。
- **新增功能点（相对 C6）：** 从「控制能力」到「完成作业」——面向产线的真实价值。
- **关键方法 / 组件：** 搜索+柔顺策略、螺旋搜索、力/位混合 + 视觉引导。
- **工业对标：** 轴孔装配、力控打磨、机器人涂胶。
- **本仓状态：** ❌ 未实现（对标缺口）。
- **验收 / 自测点：** 装配成功率、表面力一致性达标。

### C8 — 碰撞检测 / 安全反应

- **是什么：** 不依赖末端 F/T，用关节力矩/动量观测器检测意外碰撞，并做出退让/停机反应。
- **新增功能点（相对 C7）：** 从「被动接触」到「主动安全」——碰撞瞬间即感知并响应，是协作安全的关键（配合模块 06）。
- **关键方法 / 组件：** 广义动量观测器（GMO）、残差检测、反射式退让。
- **工业对标：** 无传感器碰撞检测（Franka GMO）、工业臂碰撞保护。
- **本仓状态：** ❌ 未实现；本仓有 [F42](../edge/requirements/F42-torque-direction-clamp.md)（力矩方向钳位的简易碰撞保护）与 [F50](../edge/requirements/F50-fault-monitor-watchdog.md)（偏差监控），但非模型观测器。
- **验收 / 自测点：** 轻碰可检测并退让；无误报。

## 3. 本仓可继续进阶（缺口清单）

- ❌ **C1–C8 全链为对标缺口**：起点是**采购并接入腕部/法兰六维 F/T 硬件**（[CONTROL_ROADMAP](../shared/CONTROL_ROADMAP.md) C8 前置）。
- 🔜 **接标准控制器**：模块 01 的标准栈已就绪，有 F/T 后可直接挂 `admittance_controller`（C4）。
- ❌ **碰撞检测（C8）**：可先用广义动量观测器实现无传感器碰撞检测，不依赖 F/T，性价比高。
- 🔜 **安全边界同步**：引入力控时必须更新 [SAFETY.md](../shared/SAFETY.md)（力限幅、传感器失效停机；禁止云端 200 Hz 力闭环）。
- ⚠️ **夹爪力控与末端力控的边界**：现有 F25/F33 是夹爪专用（非腕部六维），文档已明确区分，避免误当成 L8。
