# LL-161 — 标定网格采到「顶关节止挡」的位姿：止挡承重 → τ≠重力矩 → 把该关节参数整体拉偏

> **日期：** 2026-10-14
> **产品线：** Edge
> **环境：** lubancat（RK3588）Ubuntu 22.04 + ROS 2 Humble，产品 6 关节档

## 现象

6J 档全行程重力标定（F49 `--mode space`）后，示教（`ZERO_TORQUE`，kp=0）**L2 仍到处下塌**，L3 也有。拟合本身「PASS」（RMSE 0.148），但逐关节残差里 **L2 rmse=0.309 Nm**（其余 L3=0.11 / L4=0.03 / L5=0.04 / L6=0.003），且 L2 残差最大到 **±0.9 Nm** —— 远超摩擦量级。

## 根因

`space` 档网格 `l2 ∈ linspace(0, 2.4)` **从 0 起**，而 **L2 的 URDF 限位下限恰好 = 0**（`<limit lower="0" upper="3.66519">`）。这 7 个 `l2=0` 的位姿让 L2 **顶在机械止挡上**：

- 止挡分担了部分重力 → 电机实测 τ 显著**小于**重力矩（残差 −0.5~−0.9 Nm，符号一致）；
- 这些**不是重力样本**（同 LL-035 折叠位搭支撑的机理），却进了最小二乘 → 把 L2 相关参数整体拉偏 → 消费端 L2 前馈系统性欠补偿 → 示教到处下塌。

**佐证**：仅剔除这 7 个 `l2=0` 点重拟合 → RMSE **0.148 → 0.101**，L2 rmse **0.309 → 0.188**，L2 质量 **0.679 → 0.704**（更重＝补偿更足），L2 方向性迟滞 ±0.170→±0.101。

**注意**：旧 `full` 档 `l2 ∈ linspace(0.3, 1.5)` **从 0.3 起、天然避开止挡**，所以旧档没暴露这个问题——是新 `space` 档把范围放宽到行程端点才引入。

## 正确做法 / 规避

- **网格/锚点不得贴近关节限位**。已加 `--limit-margin`（默认 0.10 rad）过滤：任一关节距其限位 < 该值即剔除（`generate` 后在 `run_collection` 里用 `model.lower/upperPositionLimit` 判）；
- 同类机理也适用于：折叠 rest 位搭支撑、工具压在桌面/被支撑、臂自锁——**凡是「外力分担了重力」的位姿都不是重力样本**；
- 已采数据不必重采：把贴限位的点过滤掉写一份新 jsonl，`--optimize-only` 离线重拟合即可；
- 排查手法：把逐关节残差**对位姿作图/分组**——若某个关节残差在某段行程端点出现「符号一致的大偏差」，先怀疑止挡/支撑，而不是先怀疑算法。
