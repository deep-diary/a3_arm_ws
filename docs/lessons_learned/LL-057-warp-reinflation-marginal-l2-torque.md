# LL-057 — F57 回放时间重排两个坑：停顿被 dt 地板重新充气；逐点加速度恰解被离散伪影带飞

> **日期：** 2026-09-18
> **产品线：** Edge
> **环境：** RK3588 lubancat + ROS 2 Humble，真机 5J（L1–L5）示教回放；纯 Python 离线实验 `/tmp/f59_pass2.py`

## 现象

F57 回放时间重排（`_time_warp_points` 初版）真机验收（LL-053 同批轨迹 teach_20260917_214930.yaml）：

1. **越修越慢**：16.6 s 示教（+5 s ramp = 21.6 s 管线输入）回放被拉到 **30.9 s**，用户体感「一顿一顿、中途断点」；
2. 停顿↔运动交界速度单 tick 0→0.31 rad/s 阶跃（逐点加速度尖峰 11.4 rad/s²），3 次回放 2 次在 17.3 s / 23.3 s 触发 arm_monitor `FOLLOW_STUCK`（L2 重力负载爬升段，kp=80、重力补偿关、5 Nm 力矩限幅）。

## 根因

**坑 1：停顿重新充气。** 初版 `dt=max(s/v_eff, dt_min)` 保留全部输入点——手拖停顿段位移≈0，本应占 0 时间，却每点吃 0.02 s 网格地板；停顿越长回充气越多。时间重排只该「压缩不该拉伸」。

**坑 2（更隐蔽）：逐点加速度限幅的输入信号本身是伪影。** F59 第一版重写在 20 ms 细网格上跑「前后向分工」二次恰解，合成用例完美（3.22 s @ accel 2.00），上真实数据反而膨胀到 **38.8 s**——前后向两趟互相推翻对方上一轮的修复，dt 每轮往返增大。离线分解真实数据逐点 |Δv|：

- top-20 全部**精确等于 v_eff=0.274 rad/s**：弧长重采样用「逐段最大关节位移」，每步绑定关节的 |Δq| 按构造就 = ds = v_eff·dt_min；绑定关节在拐角换帅时，旧关节速度一步掉 0.274、新关节一步涨 0.274——这是离散度量伪影，不是电机真实需求。整条运动段 ~14% 的关节步是这种换帅步；
- 中位 |Δv| 仅 0.0168（编码器 ±1 mrad 噪声底），与换帅阶跃混在一起，逐点恰解无法区分「真拐角」与「噪声/换帅」，死区（0.08）变体两头不讨好（26.7 s 且尖峰仍 12.6）。

**物理判据**：电机沿平滑弧线路径 200 Hz 采样位置，细步速度锯齿是度量产物；单步 kink 只造成 mrad 级跟随误差暂态。`FOLLOW_STUCK` 的机理是**持续**力矩饱和（kp·err+重力 > 5 Nm 限幅 → 误差以 ~0.27 rad/s 积分，0.9 s 攒到 0.25 rad 阈值），约束必须对准**持续加速度需求**而非单步差分。

## 正确做法 / 规避

F59 终版两段式（`_time_warp_points`，参数 `playback_warp_accel_max_rad_s2: 2.0`）：

1. **弧长均匀重采样**：逐段最大关节 |Δq| 累计弧长 S，v_eff=min(S/原时长, vmax=0.6)，按 ds=v_eff·dt_min 等弧长步行走、位置段上线性插值。零弧长停顿段直接滑过、不占时间 → 停顿天然折叠，输出时长 ≈ S/v_eff ≤ 原时长（实测 21.6 s → 21.8 s；F57 版 30.9 s）。
2. **粗网格时间膨胀（变体 C）**：每 5 个细点取锚点（0.1 s 窗），在粗网格上跑同一个前后向分工二次恰解 `amax·dt²+vp·dt−Δq=0`（正根，disc<0 走有界 ×1.5 兜底），窗口内 dt 均匀回填。粗网格把噪声底从 ~5 降到 ~0.4 rad/s²（对 amax=2.0 有 5× 裕量），只响应真实拐角；实测真实轨迹粗网格最大持续加速度 0.98 < 2.0，几乎不需要膨胀。

**方法论教训**：

- 离线纯函数实验先于真机——合成用例（理想拐角）通过不代表真实数据通过，**必须用真机录制文件做回归基线**（214930.yaml 直接定性了 4 个变体）；
- 限幅器/滤波器的度量口径要对准故障的**时间尺度**：0.5 s 持续窗触发的故障，用 20 ms 差分做约束是度量错配；
- 「最大关节换帅」是 L∞ 弧长参数化的固有离散事件，任何下游逐点统计都要先排除它。
