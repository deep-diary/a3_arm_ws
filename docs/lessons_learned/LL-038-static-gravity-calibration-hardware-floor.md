# LL-038 — 静态重力标定到 0.16 Nm 就下不去了：残差是硬件非刚性效应，不是拟合问题（附「方向统计会被区域混淆」的坑）

> **日期：** 2026-09-14  
> **产品线：** Edge  
> **环境：** RK3588 (lubancat) + 真机 7J（RS00 ×3 + EL05 ×4，3D 打印外壳直连电机）

## 现象

F49 真机 68 点、12 参数拟合收敛到 **RMSE 0.1592 Nm / R² 0.9835**（旧官方 6J 参数在同批数据上
0.2036，URDF 默认 0.705）。到不了 REQUIREMENTS 的 ≤0.15，也追问过是不是采集/拟合没做对。
逐关节残差（实测 − 模型，URDF 域）：

```
L2 0.151   L3 0.297   L4 0.102   L5 0.066   L6 0.037   （双方向均值 ≈0 → 无系统偏置）
```

## 根因（是硬件，不是拟合）

四条独立证据指向「刚体模型不可表示的非刚性效应」：

1. **放开参数没用**：把 5 根杆的**全部一阶矩**（质量 + m·c 三分量，20 参数）都放开 → 0.1579
   （对 0.1592 无意义收益）；再放开 L4/L5/L6 关节原点几何（21 参数，用 `jointPlacements` 扰动，
   ±8 cm）→ 仍 0.1592。**运动学/几何误差被排除**。
2. **残差可复现**：同一 ready 位姿，一次在采集流程内（L3 77°C）、一次一小时后独立重测（L3 48°C）
   → 实测 τ 差 ≤0.04 Nm（L3 −3.643 vs −3.610），模型残差 −0.335 vs −0.302。不是随机噪声，
   也不是温度漂移。
3. **温度不是主因**：同姿态在 53–65°C 与 68–77°C 两段测得残差一致（−0.17）；早先看到的
   `corr(残差, 温度) = −0.35` 是**区域混淆**（热的点恰好集中在 L2×L3 网格那一角）。
4. **形式**：残差对 q 既非光滑单值函数（同一 q3 在 q4≈+0.5 与 −0.45 处符号相反），
   也不随「最后一次移动方向」稳定（配对样本矛盾）——即**既不是刚体几何误差也不是纯静摩擦**。

最可能是传动/结构在负载下的弹性变形（编码器在电机侧，负载端角度随力矩偏）与线束拖拽，
其角度-力矩耦合项在参数线性模型里无法表示。

**附带的坑（我第一版诊断就被骗了）**：按「相邻点 Δq 的符号」把残差分成上/下行两组，
得到 L3 ±0.2 Nm 的"摩擦"，看着很合理。但本网格**每个关节只朝一个方向扫**，上下行样本数
严重不均（24/6），且"下行"样本集中在扫描折返点（不同区域），于是把**区域相关的模型误差**
误读成了摩擦。正确做法是只取「同一位置、不同到达方向」的配对，或至少在残差按方向分组前
检查两组的位置分布是否可比。

## 正确做法 / 规避

- **把 0.15 Nm 当作本臂的物理地板来验收**，不是拟合目标：`run_optimize` 现在打印逐关节
  残差/偏置 + 方向性迟滞 + 「扣掉方向项后的 RMSE」并按 ≤0.15 出 PASS/FAIL，yaml 里写
  `accepted: true/false` 与 `rmse_per_joint`，**不达标也照写 yaml（附 accepted: false）**——
  因为新参数在所有指标上都优于旧参数，比留在旧 yaml 强。
- **验收位姿必须是 free 位姿（ready）**：折叠 home 位臂搭在支撑上、τ 恒 ≈0，模型 vs 实测
  的差全是支撑力，判不了标定（LL-035）。
- **判断"拟合没做好"的检查顺序**：① 域换算（LL-037）；② 参数顶边界；③ 逐关节偏置是否 ≈0；
  ④ 放开更多参数看 RMSE 降不降；⑤ 同姿态重复测量看残差是否可复现。①②③ 是拟合问题，
  ④⑤ 指向硬件。
- 想再降误差只剩非参数手段：ready/home 这类**固定工作位做开机 tare**（比对模型与实测，
  把残差当常数偏置补偿），不要指望再采一批数据——同一姿态换个到达方向仍是同样的残差。
