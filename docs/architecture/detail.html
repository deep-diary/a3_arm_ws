关键行为：F42 力矩方向钳位（增矩方向冻结、反向放行、新轨迹清 latch）；F46 TX 帧率监视（5 s 窗口先发布再清零）；F51 使能安全门禁（反馈不新鲜整体拒使能、目标重锚反馈位、kp 软起步 0.8 s）；失能态保持抑制 latch（stop 后只发零增益保活帧）。参数全部在 control_gains.yaml（kp=80/kd=2.0、joint_signs、torque_protection_limit_nm、F52 档位等）。

arm_monitor 看门狗（F50/F51）

独立节点，只做跨数据源比对、通过公开服务动作，不接管现有保护。
故障类触发条件处置
FOLLOW_STUCK运动窗口 max|q_d−q_actual| > 0.25 rad 持续 0.5 sstop → 3 s 未消升级 reset
HOLD_DRIFTREADY 保持期末点 vs 实际 > 0.30 rad 持续 1.0 sstop → 升级 reset
STALE_JSjs 过期 > 1.0 s 且 state ∈ {READY,TRAJ,SAFE_PARK,SERVO,TEACH,AI}reset（反馈死亡）
UNEXPECTED_DISABLEstate ∈ {READY,TRAJ,SAFE_PARK} 但电机 enabled=false 持续 0.5 s仅报告（编排层转 DISABLED）
TEMP_UNRESPONSIVE温度 ≥95 °C 且 state ∉ {COOLING,SAFE_PARK,FAULT} 持续 3 sreset（F44 失灵兜底）
输出 /a3/monitor/status（20 Hz）：status=OK/PENDING/TRIGGERED（fault 只表示已确认）；抑制：ZERO_TORQUE/GRAVITY_COMP 跳过运动类、启动 3 s 宽限、触发 5 s cooldown、条件消失 +2 s 回 OK；意图边界重基准（F51）清运动窗口。

仿真栈对应（无 CAN 闭环）

仿真 launch 用 sim_motor_node / sim_power_sequence_node / sim_executor 等价替代真机节点，同一话题/服务契约（sim 有意不实现 gate 互锁与部分安全机制）。
真机仿真替代差异
motor_protocol_nodesim_motor_node（edge_web_sim 内以 name=motor_protocol_node 起）一阶跟随 + L7 接触弹簧力矩；提供 /a3/motor/* 全服务（含 F32 MIT 保持/扫描）
power_sequence_nodesim_power_sequence_nodegate 恒 true、state=Running（1 Hz 重发）——仿真有意不实现互锁
can_transport_node + SocketCANsim_executor（track 轨迹 → /joint_states 50Hz）无 CAN 帧层，仅轨迹插值
—zero_to_ready_publisher（Wave A）延时下发 zero→ready 轨迹
仿真验收入口：edge_sim_wave_a.launch.py（Wave A）、edge_moveit_execute.launch.py use_sim:=true（Wave B）、edge_web_sim.launch.py（Web 全链路）。
