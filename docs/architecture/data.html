MQTT telemetry points 目录（上行）

a3_mqtt_bridge 经 bridge.yaml 白名单展平；code 须与 deep-trace 设备 YAML 完全对齐（跨仓耦合）。
来源话题展平规则points key 示例
/joint_statesjoint_statepos_L1..L7、vel_*、eff_*（BEST_EFFORT；eff 为电机域原值 LL-037）
/a3/gravity_torquejoint_statetau_g_L1..L7
/a3/control_mode · /power_sequence/gate_open · statescalarcontrol_mode、gate_open、power_state
/a3/arm_statusscalar（2 条 rule）arm_state / arm_mode / arm_message / arm_temp_warn；mtqmax_L1..L7（F43）
/a3/gripper_statusscalargrip_state / grip_mode / grip_target_torque / grip_actual_torque / grip_position / grip_target_position / grip_contact / grip_error
/a3/motor/statesmotor_statetemp/err/mode/online/mtq/mp_L1..L7（6×7=42 点，F32）
/a3/motor/tx_statsjoint_state + scalartxhz_L1..L7、tx_window_s、tx_traj_total、tx_refresh_total、tx_rate_ok（F46）
/a3/monitor/statusscalarmonitor_status / monitor_fault / monitor_action（F50，二期规划）
速率契约：telemetry 全量聚合 ≤5 Hz（最新值胜出，可丢）；device/info、device/status、cmd_result 永不丢、不受节流；NaN/±Inf 递归清洗（F31/LL-011）。
