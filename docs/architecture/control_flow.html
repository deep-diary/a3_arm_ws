初始化闭环 init → enable → READY

/a3/arm/init（设零→异步确认→使能）与 /a3/arm/enable（F48 读数门禁 + F51 重锚/软起步）
sequenceDiagram
    participant Web as Web / 调用方
    participant AC as arm_controller
    participant MP as motor_protocol_node
    participant JS as /joint_states

    Web->>AC: /a3/arm/init (Trigger)
    AC->>MP: /a3/motor/set_zero（广播）
    MP->>JS: 设零后反馈
    loop 轮询确认
        AC->>JS: 读 7 关节位置
    end
    AC-->>Web: success n/7（如 7/7）
    Web->>AC: /a3/arm/enable
    AC->>AC: F48 门禁：读数在 URDF 限位内 && js 新鲜
    alt 越限 / 陈旧
        AC-->>Web: 拒绝，点名关节与限位
    else 通过
        AC->>MP: /a3/motor/enable（F51：重锚反馈位 + kp 软起步 0.8s）
        MP-->>AC: 响应（重锚 N 电机…）
        AC->>AC: 状态 READY
        AC-->>Web: success
    end
