MQTT 上/下行时序

sequenceDiagram
    participant NODES as ROS 节点（arm/gripper/motor/monitor）
    participant BR as a3_mqtt_bridge
    participant EMQX as EMQX
    participant WEB as Web 浏览器（mqtt.js WS）

    loop 各话题回调
        NODES->>BR: 状态/遥测消息
        BR->>BR: 展平 points + NaN 清洗 → 缓存置脏
    end
    loop flusher 0.05s（5Hz 上限）
        BR->>EMQX: telemetry（全量 points，最新值胜出，可丢）
    end
    BR-->>EMQX: device/info · device/status（retained，永不丢）
    WEB->>EMQX: cmd {op, args}（QoS1）
    EMQX->>BR: cmd
    BR->>BR: op 白名单校验
    alt 参数非法
        BR->>EMQX: cmd_result ok=false
    else 合法
        BR->>NODES: 调 /a3/arm|gripper|motor 服务
        NODES-->>BR: success/message
        BR->>EMQX: cmd_result {op, ok, message, ts}（永不丢）
    end
    EMQX-->>WEB: cmd_result / telemetry
遥测队列满只丢遥测；发布在独立线程，broker 慢不阻塞 cmd 处理与回执。

分层保护信号（跨节点）

同一故障的不同观察视角 → 各自职责内的处置，不越权（F50 原则）。
sequenceDiagram
    participant EXEC as motor_protocol（执行层）
    participant MON as arm_monitor（看门狗）
    participant AC as arm_controller（编排层）

    Note over EXEC: F42 力矩方向钳位（200Hz latch）——撞堵立即冻结目标
    EXEC->>EXEC: trip + latch 符号，目标钉在反馈位
    Note over AC: F44 温度保护——warn 90 / protect 95
    AC->>AC: READY→SAFE_PARK→COOLING（回 home 后失能）
    Note over MON: F50 跨源比对（期望 vs 实际）
    MON->>MON: 20Hz 检查 tracking_errors / js 新鲜度
    alt FOLLOW_STUCK 持续 0.5s
        MON->>EXEC: /a3/motor/stop
        Note right of MON: 3s 未消 → /a3/motor/reset
    else STALE_JS
        MON->>EXEC: /a3/motor/reset
    end
    Note over AC: 消费 MonitorStatus（只认 TRIGGERED）→ DISABLED
    AC->>AC: 本地兜底 unexpected_disable_sustain_s 1.0s
