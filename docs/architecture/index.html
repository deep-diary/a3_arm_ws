A3 Arm Platform — 软件架构图集

EDULITE A3 七自由度机械臂 · ROS 2 Humble · RK3588 / SocketCAN / MIT 电机 / PS4 遥操作
双产品线：A3 Edge（RK3588 板载全栈，主线）· A3 CloudEdge（内网服务器 + ESP32-S3，支线）
以 Mermaid 流程图 为主展示宏观/微观架构、控制流与信号流
需联网加载 CDN（jsdelivr）· 配套 Markdown 真源见 docs/edge|cloud_edge|shared

2026-09 架构决策与落地现状： 现场主路径为 A3 Edge——RK3588 板载完整 ROS 2 栈，SocketCAN（默认 can1，1 Mbps）直驱 7× MIT 电机（ID 1..7，主机 0xFD）； 所有执行层指令收敛到轨迹总线 /joint_group_effort_controller/joint_trajectory，由 motor_protocol_node 以 ≤200 Hz 插值下发 MIT 帧，反馈 50 Hz 发布 /joint_states。 编排门面 a3_arm_controller（11 态状态机 + 统一服务 /a3/arm/* + /a3/arm_status 10 Hz）为对外唯一交互入口； 独立看门狗 a3_arm_monitor（F50）做跨数据源比对与分级处置（stop→reset）。 Web 遥测/控制经 a3_mqtt_bridge ↔ EMQX（前缀 deep-trace/HOME-DEMO/RK3588/，5 Hz 节流，指令 op 白名单 + cmd_result 回执）。 已落地关键机制：F40 失能保护 park、F42 力矩方向钳位、F44 温度管理、F46 TX 帧率监视、F48 使能位置门禁、F49 重力标定、F50 看门狗、F51 使能安全门禁（重锚+软起步+保持抑制）、F52 缺电机降级档（7J/6J/5J）。 CloudEdge 支线：内网服务器集中规划（MoveIt/Pinocchio）+ ESP32-S3 micro-ROS 本地 200 Hz 插值 + CAN；本仓仅含 Linux 端 Agent/mock 验证栈。 细节真源：docs/edge/ARCHITECTURE.md · docs/shared/TOPIC_CONTRACT.md · docs/edge/REQUIREMENTS.md（F 系列）。
