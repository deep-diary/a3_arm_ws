原则：上层可调用下层；执行入口唯一（轨迹总线）；编排层对外门面、执行层权威拦截；分层保护（F42 执行层 200 Hz / F44·F40 编排层状态机 / F50 独立看门狗）；遥测统一经 MQTT 桥白名单展平上云。主路径 = A3 Edge：PS4/Web/MoveIt 的指令 → 轨迹总线 → motor_protocol 200 Hz 插值 → SocketCAN MIT 帧 → 7 电机；反馈 50 Hz 回 /joint_states → 编排聚合 + 遥测上云。CloudEdge 支线：服务器集中规划 → gravity_compensation_node 填 effort 前馈 → micro-ROS Agent → ESP32 本地 200 Hz 插值 + CAN（本仓仅 Linux 端验证栈）。

数据流编号速查（D/U · From → To）

■ 蓝=下行（控制/命令/配置），■ 绿=上行（反馈/状态/遥测）。逐跳细化见《信号流》页。
编号From（发出方）To（接收方）说明
■下行1arm_controller / gripper / FJT / trajectory_bridge / servo / gravity（CloudEdge）轨迹总线 → motor_protocol所有执行层指令统一收敛到 /joint_group_effort_controller/joint_trajectory（JointTrajectory，effort 为开环重力前馈）
■下行2PS4（F3） / topicpower_sequence_node电源命令 start / shutdown / set_zero
■下行3motor_protocol / power_sequencecan_transport_nodeMIT 控制帧与电源控制帧 → /can_tx_frames
■下行4can_transport_nodeSocketCAN → 电机物理 CAN 帧（1 Mbps，≤200 Hz/电机）
■下行5Web 浏览器（MQTT cmd）a3_mqtt_bridge → arm/gripper/motor 服务op 白名单：init/enable/disable/goto/set_joints/teach/save/playback/enter_ai/exit_ai/gripper_*/motor_*
■下行6config YAML（控制增益/限位/档位）各节点参数control_gains / motor_map / power_sequence / bridge / F52 档位（7J/6J/5J 配对）
■上行1电机 → SocketCANcan_transport_node反馈帧回传
■上行2can_transport_nodemotor_protocol_node/can_rx_frames → MIT 编解码
■上行3motor_protocol_node状态总线 / 遥测源/joint_states（50Hz，BEST_EFFORT，注意域差异 LL-037）+ /a3/motor/states + /a3/motor/tx_stats
■上行4arm_controller / gripper_controllerMQTT 桥/a3/arm_status（10Hz，arm_state/mode/message/temp_warn + mtqmax_*）与 /a3/gripper_status（grip_* 8 信号）
■上行5arm_monitor_nodeMQTT 桥/a3/monitor/status（20Hz：OK/PENDING/TRIGGERED + 处置动作）
■上行6a3_mqtt_bridgeEMQX → Webtelemetry（5Hz 最新值胜出）/ device.info / device.status / cmd_result（永不丢、不受节流）
■上行7ESP32（CloudEdge）服务器joint_states XRCE 回传（支线）

双产品线对照

完整背景见 docs/README.md 与 cloud_edge/ARCHITECTURE.md
维度A3 Edge（主线，active）A3 CloudEdge（支线，draft）
单臂主控RK3588（Linux + ROS 2 全栈）ESP32-S3（固件）+ 内网服务器
轨迹规划板载 MoveIt / reBot 工具链服务器集中规划（多臂共用一套）
CAN 执行SocketCAN → a3_can_bridgeESP32 TWAI/CAN，本地 200 Hz 插值
控制延迟板内 < 10 msWiFi 轨迹块下发 + 边缘插值
网络依赖无（本地闭环）WiFi 必须
单臂 BOM较高较低
适用场景单机低延迟力控、现网部署多臂实验室、降本量产、MCP 编排
本仓承载全栈 11 包仅 a3_cloud_edge（Agent/mock 验证栈）
